# @haeckmec/grounded-chat

Grounded chat SDK: an LLM chat that only states figures and facts the host app's own tools returned, refuses guesses, and proves it with a judge and evals.

**The API is not stable until 1.0.** Pin an exact version and read `CHANGELOG.md` before upgrading.

Install, the `.npmrc` for GitHub Packages and the subpath list: see the [repository README](https://github.com/haeckmec/grounded-chat#readme).
