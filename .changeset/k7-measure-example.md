0.1.0, the first published release. `measureFigures` and `findMeasureSpans`: a figure class for volumes, dashes and drops, parts and percent strength, for packs whose facts are specs and ratios. Every export now carries a doc comment, enforced by an API review test. `examples/grounded-kb` is a complete second pack (tools, measures, a one-slot intake plan, its own judge verdict, server, widget and admin on the dummy adapter), and `npm run check:packed` runs it on the packed tarball outside the workspace, in CI and before every publish.
