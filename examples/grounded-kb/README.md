# grounded-kb example

A synthetic knowledge-base pack that consumes `@haeckmec/grounded-chat` like an outside app: a lookup tool, `measure` figures, an "unverified" label rule and its own judge verdict, all on the dummy adapter.

Today it only proves that every subpath of the built package resolves by its public name (`test/subpaths.test.ts`). The pack itself lands once the kernel exists.
